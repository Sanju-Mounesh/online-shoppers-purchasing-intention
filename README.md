# Online Shoppers Purchasing Intention Analysis

## Project Overview

This project explores online shopping session data to understand customer behaviour and purchasing intention.

The analysis uses Python to investigate patterns in browsing activity and examine factors associated with whether a shopping session results in a purchase.

## Dataset

- **Number of sessions:** 12,330
- **Number of features:** 18
- **Target variable:** Revenue
- **Missing values:** None identified during the initial data inspection

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Work

The notebook covers:

- Initial data inspection and exploration
- Data quality checks
- Exploratory data analysis
- Data visualisation
- Customer purchasing behaviour analysis
- Machine learning methods explored in the coursework

## Project Structure

- `online_shoppers_analysis.ipynb` — Jupyter Notebook containing the analysis.
